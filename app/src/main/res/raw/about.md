# 关于

版本 1.0.0

植物大战僵尸2 中文版的本地碎片记录工具，数据只保存在手机上，离线可用。

## 功能

- **碎片记录**：按可探险/状态/颜色三级分组，逐层折叠，点加减按钮记碎片。
- **手动升阶**：碎片够了只提示「可升阶」，阶数自己改，不会自动扣碎片。
- **其他道具**：五种颜色的已有数量与需求都可加减，数量不设上限。
- **备份恢复**：可导出为 JSON，导入时支持覆盖或合并。

- 植物图片与道具图标来自植物大战僵尸2 中文版官方图鉴：https://pvz2.hrgame.com.cn/books?type=10
